# Contributor Instructions

- Write source code, identifiers, comments, docstrings, build-script comments, logs, and technical messages in English.
- Development communication and internal project documentation can maintain Simplified Chinese counterparts (stored under `docs/archive/zh-CN/`).
- External-facing public releases, user guides, and root repository presentations (e.g. `README.md`, Release Notes) are strictly published in English only.
- Keep code samples and their comments in English.
